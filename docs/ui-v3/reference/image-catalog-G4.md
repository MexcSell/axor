# Image spec, group G4 (40-1 .. 40-14): AXoR "Autonomous AI Company OS" mockups

All 14 images are ~1672x941 (16:9) renders, dark "luminous neon / sci-fi glass" style, AI-generated concept art (some text is slightly garbled; transcribed as legible). They are alternate design explorations of the same product; the shell is the same family but varies per image.

## SHARED SHELL (describe once)
- Theme: dark, deep navy/near-black space (#050A1A to #0B1230) with a glowing futuristic city skyline hero banner at the top (floating islands, neon towers, holographic globe/dome with a glowing "A" logo, drones, spaceships). Hero art occupies the top ~0-18% of height, behind header and under/around page title. Content panels float over it.
- Panels: glass cards, bg ~#0A1535 at 70-85% alpha with slight vertical gradient (#0E1D45 to #08102A), 1px neon border (cyan #2FA8FF / blue #3B6CFF / purple #8A4DFF depending on panel accent), radius ~12-16px, outer glow (box-shadow 0 0 12-20px of border colour at ~35%), subtle inner top highlight. Inner list rows are darker inset (#0B1A3C) rounded 8-10px.
- Header (top-left): logo mark = glowing blue-to-violet gradient triangular "A" with orbit ring + wordmark "AXoR" with small "TM" (white, bold, wide sans, ~34px) ; thin vertical divider; title "Autonomous AI Company OS" (white, semibold ~22px); subtitle "A Self-Sustaining · Self-Evolving · Goal-Driven AI Company" (light grey-blue #B8C6E6, ~12px).
- Header (top-right): in most images a pill/toolbar group of 5 lifecycle steps with icons: Plan (shield-check / list), Execute (curved-arrow / rocket-ish), Verify (shield with check / paper-plane check), Evolve (gear-orbit / DNA-ish / atom), Sustain (gear-star in gold/orange). Icon colours: cyan, cyan, blue, violet, gold. Then a notification bell with red badge "3" (12 in 40-14), a "?" help circle icon, a settings gear, and sometimes a user avatar (round gradient "A") or fullscreen/grid icon. Some images show them as a pill with chevrons between steps (40-11: Plan > Execute > Verify > Evolve > Sustain).
- Left sidebar: ~0-12% width, vertical glass panel starting ~y=10%, rounded 16px with glowing border. Nav items (icon + label, 15-16px white/grey #C9D6F2, ~38-48px row pitch). Standard item order: Overview (house), Missions (target/bullseye), Mission Control (node tree) [some images], Agents (robot head), Organization (org-chart nodes), Versions & GitHub (git branch), Evolution Lab (atom / flask / DNA), Knowledge (open book), Finance (coin stack / database), Governance (shield with plus), Appearance (palette), Settings (gear). Active item: filled gradient pill (blue #2B6BFF to violet #7B3CFF in some; cyan outlined glow in 40-5) with white bold text and glow. Bottom of sidebar: a holographic glowing island / platform thumbnail illustration and a version card "AXoR v2.4.0" with green dot "Online" (40-1 shows "v1.5.0 • Online").
- Common widgets: KPI tiles (icon left, big number white 28-32px bold, label grey, delta in green with up-arrow "↑ +2"), circular gauge "98%" (ring gradient green to cyan to yellow, track dark), "Company Health" checklist rows with green check-circles and right-aligned values, status pills (green "Active"/"In Progress"/"Connected", amber "At Risk"/"Warning", purple "Review", red "Critical"), progress bars (cyan-to-blue gradient fill on dark track, rounded fully), toggles (green #22E06B on, grey off), segmented tabs (active = gradient filled pill violet/blue with glow; inactive = dark with grey text), "View All →" cyan links, "?" circular help icon next to many panel titles, "..." overflow menus.
- Palette: bg #050A1A / #0A1230; panel #0B1638; border cyan #2EA8FF, blue #3366FF, purple #8B4DFF, gold #E0A52E (Organization 40-8); text white #FFFFFF, secondary #AFC0E6, muted #7F90B8; accent blue #2F7BFF, cyan #22D3EE, violet #8B5CF6, magenta #D946EF; status green #22C55E/#2EE66B, amber #F5A524, red #EF4444, orange gold #F59E0B.
- Typography: geometric humanist sans (Inter/Segoe-like, Exo-ish for title), weights 400/600/700, numbers bold; text has faint glow on headings; icons are glowing line icons with duotone neon gradient fills.
- Functional baseline: sidebar nav routing; top-right icons open notifications/help/settings; panels with "View All" navigate to full lists; progress/percent values update live; toggles/segments/dropdowns persist state; responsive tab switching.
